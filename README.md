# ISense

把触动你的每一句话,安安静静地留下。

## 简介

ISense 是一款本地优先的「金句收藏」App。你输入的每一句金句都只存在本机 iOS 系统偏好(UserDefaults)中,不上传任何服务器。

## 主要功能

- 一句话快速记录(粘贴识别)
- iOS 桌面 Widget
- 系统分享面板扩展(任意 App 中选中文字即可保存)
- 珍藏分类
- 一键清除本机数据
